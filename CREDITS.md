# Credits and scope

The Pacman AI projects were developed at **UC Berkeley**, primarily by **John DeNero** and **Dan Klein**. Student-side autograding was added by **Brad Miller**, **Nick Hay**, and **Pieter Abbeel**. See [Berkeley AI](https://ai.berkeley.edu/) and [Project 1, Spring 2026](https://inst.eecs.berkeley.edu/~cs188/sp26/projects/proj1/).

This companion downloads the unmodified [official Python 3 starter archive](https://inst.eecs.berkeley.edu/~cs188/sp26/assets/projects/search.zip) into the ignored `berkeley_pacman/` folder. It does not redistribute that archive, completed assignment solutions, or answer files. The download is verified against SHA-256 `d212f664b97ee38548dd868dfc5ce187f1a2147cfb90b0469e4fffe6e0a160c3`.

Berkeley's source-file notices permit educational use and extension subject to retaining the notices, attributing UC Berkeley, linking to Berkeley AI, and not publishing solutions. Keep those notices intact. The teaching prompts create search implementations only in a student's local, ignored copy. Do not upload that folder when publishing a class repo.

The Python launcher, browser renderer, prompts, tests, cost-maze layout, and customization hooks in this repo are new companion materials. Berkeley owns its original code; this companion is not an official Berkeley release. The browser uses Berkeley's real `GameState` transitions, scoring, ghosts, and layouts. It draws those states with HTML canvas instead of Tk.

Only navigation search and simple behavior rules are in scope. This is not the full CS 188 multi-agent, reinforcement-learning, or inference curriculum. No connection to an AI service is made by the game. AI assistance happens in the student's chosen coding assistant.
