# Instructions for coding assistants

- Read README.md and the relevant guide in instructions/. Keep student explanations under 100 words unless asked for more. Explain before running. Finish with a working view and one observation to look for.
- The numbered recipes are in the visible prompts/ folder. If an idea placeholder is unfilled, ask for the student's idea and wait. Do not invent their heuristic or behavior rule.
- Detect the Python command: Windows `py -3` or `python`; Mac/Linux/Codespaces `python3`. Python 3.10+ works; recommend 3.12 or newer. No pip packages or API keys are required.
- Install with `start_pacman.py install`; verify with `start_pacman.py check-installation`. The official project is downloaded into berkeley_pacman/, intentionally ignored by Git. Never publish its completed search functions. Preserve attribution headers and signatures. Implement only the requested function in berkeley_pacman/search.py; leave other TODOs and the engine unchanged.
- Search functions must use SearchProblem, return legal direction lists, terminate on cycles and no route (return []), and handle a start that is already the goal. BFS minimizes steps; UCS uses non-negative edge costs and replaces worse paths; A* uses g+h, updates better g, and reopens a state reached more cheaply. Do not copy external solutions.
- Test changes with `python3 -m unittest discover -s tests -v`, using the detected Python command. Unbuilt searches are skipped. Also run the requested experiment with --display text before showing its visual result. Fix relevant failures.
- For search lessons use --display browser to show exploration and playback. The default start command opens a program menu. Named programs automatically use a working desktop window or the browser; a missing desktop window is recovered automatically. Do not install Tk just to run the game.
- Keep the game terminal running. If our viewer is already running, use its controls or restart only our own terminal. Do not start duplicate servers on one port or kill unrelated processes. --no-open-browser prints the link without opening a tab.
- In Codespaces use the actual forwarded link or Ports → 8000 → Open in Browser, with a private port. Never tell a browser-based Codespaces user to open their computer's localhost. Locally, use http://localhost:8000. A remote agent cannot open a desktop window on the student's computer.
- If a remote agent cannot expose a port, run `start_pacman.py <program> --save-replay saved_replays/<program>.html` and attach the standalone replay. Interactive play still needs the local or Codespaces server. Never claim your remote localhost is accessible to the student.
- Custom A* idea: edit only my_astar_heuristic.py and keep estimate(position, goal). Require finite non-negative values and 0 at the goal. Explain possible overestimation. A consistency check on one maze is not a proof for all mazes. Public command: `start_pacman.py astar-search --heuristic my-heuristic`.
- Custom behavior: edit only my_pacman_behavior.py and keep choose_move(context, memory). Return a legal direction. memory lasts one game. Coordinates use (x,y), bottom-left origin. Do not alter scoring, physics, or ghosts to make a rule look successful. Public command: `start_pacman.py my-pacman`.
- Copilot must have permission to edit and run commands (Agent mode). A chat-only assistant should provide edits and commands and clearly say it cannot execute them. Never report installations, checks, or opened tabs that you did not perform.
